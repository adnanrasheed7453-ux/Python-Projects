# Student Pass/Fail Prediction

## Project Overview

This project is a machine learning-based Student Pass/Fail Prediction system developed using Python. The main purpose of this project is to predict whether a student is likely to pass or fail based on academic and study-related factors.

## Features

* Data preprocessing and cleaning
* Handling missing values
* Encoding categorical data
* Feature scaling
* Training and testing the machine learning model
* Student pass/fail prediction
* Model performance evaluation

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Logistic Regression
* Random Forest
* StandardScaler
* Label Encoding

## Dataset

The dataset contains student-related information such as attendance, study hours, and marks. The target variable indicates whether the student passed or failed.

## Project Structure

* `student_prediction.py` — Main Python source code
* `students.csv` — Dataset used for training and testing
* `README.md` — Project documentation

## Purpose

This project was developed to practice data preprocessing, feature engineering, machine learning model training, and prediction using Python. It demonstrates how machine learning can be applied to educational data to analyze student performance and make predictions.
